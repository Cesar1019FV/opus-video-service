# 🌐 Translation System (i18n)

The internationalization system for **Opus Video Service** allows the CLI to operate in multiple languages. It currently supports **English (en)** and **Spanish (es)**.

## 📂 File Structure

The translation logic is located in `src/translations/`:

- `manager.py`: The core of the system. Loads the selected language and provides the `t()` function to retrieve strings.
- `en.py`: Master dictionary with English strings.
- `es.py`: Dictionary with Spanish translations.
- `settings.json`: (Autogenerated) Stores the user's language preference.

## 🚀 How it works

1.  **Startup**: When the program runs, the `Translator` reads `settings.json`. If it doesn't exist, it triggers a CLI prompt for you to choose a language.
2.  **Code Usage**: In any CLI or shared file, we import the translator:
    ```python
    from src.translations.manager import get_translator
    t = get_translator().t
    
    # Simple usage
    print(t("menu_title"))
    
    # Usage with variables
    print(t("video_ready", path="/path/to/video.mp4"))
    ```

## ➕ How to add new strings

If you are building a new feature and need to add messages:

1.  Open `src/translations/en.py`.
2.  Add a new descriptive key to the `TRANSLATIONS` dictionary.
    ```python
    "my_new_feature_prompt": "Enter the name:",
    ```
3.  Repeat the process in `src/translations/es.py` with the corresponding translation.
4.  Use `t("my_new_feature_prompt")` in your code.

## 🌍 How to add a new language

To add, for example, **Portuguese (pt)**:

1.  Create `src/translations/pt.py` following the `en.py` format.
2.  Modify `manager.py` to recognize "pt" in the `load_translations` method.
3.  Update the initial prompt in `src/main.py` to include "pt" in the `choices` options.
